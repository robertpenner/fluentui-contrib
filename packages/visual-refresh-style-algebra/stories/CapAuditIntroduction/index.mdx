<Title>CAP Button audit</Title>

This page answers a practical question: when an app chooses Button props, what does Fluent do with those inputs, what styles does CAP apply, and can an independently written implementation reproduce the result?

The audit covers a focused set of Button inputs, compares the visible results, and then checks browser-dependent behavior such as forced colors and reduced motion. These checks tell us what the current code does. They do not establish which combinations a product has committed to support, so product support remains unknown.
